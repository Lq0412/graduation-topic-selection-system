# 选题系统上线数据准备说明（给院系负责老师）

系统地址：https://topic.lqlab.cn

请协助提供以下 **3 份表格**。所有表格请用本目录下的 CSV 模板填写，**不要改动列顺序**，不要新增或删除列。

---

## 需要提供的 3 份表

| 序号 | 表格 | 用途 | 谁填 |
| --- | --- | --- | --- |
| 01 | 院系专业填报表 | 建组织架构，决定学生能看到哪些题 | 院系教务 |
| 02 | 教师名单 | 批量开通指导老师账号 | 院系教务 |
| 03 | 学生名单 | 批量开通学生账号 | 院系教务 |

> **题目不需要提供表格。** 题目由各位指导老师登录系统后自行发布、提交审核，系部主任在系统中审核。

## 01 院系专业填报表

列：`系部名称,专业名称,选题组名称`

| 列 | 填写说明 |
| --- | --- |
| 系部名称 | 如「计算机系」。**全系统唯一，改名会导致历史数据失配** |
| 专业名称 | 如「计算机科学与技术」，必须挂在某个系部下 |
| 选题组名称 | 可选。用于按组限制学生可选题目范围；**同一个组内学生能选同样的题**。不分组可留空 |

示例：

```
系部名称,专业名称,选题组名称
计算机系,计算机科学与技术,计算机科学与技术组
计算机系,软件工程,软件工程组
计算机系,人工智能,人工智能组
```

## 02 教师名单

列：`工号,姓名,系部,专业,最大出题数量,临时密码`

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 工号 | ✅ | 登录账号，全系统唯一 |
| 姓名 | ✅ | 真实姓名，学生选题时显示 |
| 系部 | ✅ | **必须与 01 表的系部名称完全一致** |
| 专业 | 建议填 | 同样要与 01 表一致，留空也可以 |
| 最大出题数量 | ✅ | 正整数，该教师最多能发几个题 |
| 临时密码 | 可留空 | **建议整列留空，由技术人员统一生成** |

示例：

```
工号,姓名,系部,专业,最大出题数量,临时密码
2021001,张老师,计算机系,计算机科学与技术,8,
2021002,李老师,计算机系,软件工程,6,
```

## 三个最容易出错的地方（请务必注意）

1. **系部、专业名称必须三张表完全一致**
   系统靠文字精确匹配，`计算机系` 和 `计算机学院` 是两个不同的系部。填之前先定好标准名称。

2. **文件必须存成 CSV UTF-8 编码**
   Excel 直接「另存为 CSV」默认 GBK，导入后中文会变乱码。
   正确做法：Excel「文件 → 另存为 → 其他格式 → CSV UTF-8（逗号分隔）」。
   更稳妥：填完直接发 .xlsx 原文件过来，由技术人员转码。

3. **临时密码整列留空最省事**
   系统要求每个账号的临时密码至少 12 位且**互不相同**，人工编很容易重复导致整表导入失败。留空由技术人员批量生成即可。

## 还需要一并确认的 5 项规则

这些是系统开关，需要老师拍板：

1. **每位学生最多能预选几个题目？**
2. **每位教师出题上限是否统一？**（也可在教师名单里逐个指定）
3. **选题时间窗**：预选开放时间、正式确认开放时间（具体日期和时刻）
4. **是否允许跨系选题？** 允许的话，各系允许选哪些系？
5. **系部主任名单**：需要几位主任？工号和姓名（主任账号由管理员在后台单独建）
